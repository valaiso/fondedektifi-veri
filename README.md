# Fon Dedektifi · Veri

Fon Dedektifi uygulamasının günlük veri yayını.

- Hafta içi her akşam güncellenir.
- Fon notları "Çok yüksek / Yüksek / Orta / Düşük / Çok düşük" kalite etiketleriyle yayınlanır.
- Kaynak veri bozuk ya da eksikse yayın durur, bir önceki gün yerinde kalır.
- `data/build.json`: son güncelleme zamanı, son fiyat günü ve veri biçimi sürümü.

| Not | Etiket |
|---|---|
| A+ | Çok yüksek |
| A | Yüksek |
| B | Orta |
| C | Düşük |
| D | Çok düşük |

Fon notları TEFAS'ın herkese açık verilerinden hesaplanır. Yatırım tavsiyesi değildir ve kişiye özel değildir.
Takasbank, TEFAS veya herhangi bir portföy yönetim şirketiyle bağlantısı yoktur.
